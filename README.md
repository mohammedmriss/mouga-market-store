# Mouga Market

متجر إلكتروني ثابت وخفيف بالدارجة المغربية، مع أداء عند الاستلام. واجهة المتجر HTML/CSS/JavaScript بلا إطار عمل ولا dependencies ديال الموقع. البنية فيها Worker لحماية الطلبات، Google Apps Script لتخزينها، وواجهة إدارة كتحدّث ملفات JSON فـ GitHub.

## شنو خاص يتبدل قبل الإطلاق

- حط الدومين الحقيقي فـ `order-worker/wrangler.toml` داخل `ALLOWED_ORIGINS`، وبدّل `OWNER` باسم حساب GitHub.
- زِد رابط المتجر الحقيقي فـ `robots.txt`، وشغّل مولّد صفحات المنتجات مع `SITE_URL`.
- بدّل البريد الوهمي فـ `contact.html`، وكمل سياسة الإرجاع والتوصيل والخصوصية بالمعلومات الحقيقية.
- من بعد نشر الـWorker، حط رابطو فـ `data/config.json` فـ `order_endpoint`. دير commit وpush لهاد التغيير.
- الصور والمنتوجات والأسعار التجريبية فـ `data/products.json` غير أمثلة؛ بدّلها قبل البيع.
- `ALLOWED_ORIGINS` خاصها تطابق أصل الموقع بالحرف، مثلا `https://shop.example.ma` بلا `/` فالأخير.

## التطوير والتحقق

ما كاين حتى dependency للموقع. Node.js 20+ مطلوب غير للسكريبتات والاختبارات:

```powershell
npm test
npm run check
node scripts/secret-scan.mjs
node scripts/generate-product-pages.mjs
```

شغّل مولّد SEO من بعد كل تغيير فالمنتوجات. تقدر تعاود توليد `sitemap.xml` وتراجع الصفحات الجديدة قبل النشر. `node scripts/minify.mjs` اختياري كينسخ ملفات الموقع لـ `dist` ويصغّر CSS بلا dependencies؛ راجع إعداد Pages إلا بغيتي تنشر `dist` بدل جذر المستودع. صفحة الإدارة متاحة فـ `/admin.html` وما مفهرساش.

## قائمة اختبار يدوية قبل الإطلاق

- جرّب تسجيل الدخول، تحديث الصفحة، فتح تبويب جديد ثم تسجيل الخروج.
- زِد/بدّل/حذف منتوج؛ جرّب الفئات وتأكد أن حذف فئة مستعملة مرفوض.
- بدّل ألوان المتجر وإعداد الإعلان، وتأكد من النتيجة فالمتجر.
- جرّب إضافة منتوج للسلة، تغيير الكمية، حذفو، وتحديث الصفحة.
- جرّب منتوج عندو لون أو مقاس: الاختيار ضروري قبل الطلب.
- جرّب أرقام الهاتف `0612345678` و`0712345678` و`+212612345678`، ورقم غير صالح.
- دير طلب تجريبي وتأكد أنه تسجل فالجدول ووصل إشعار Telegram، ومن بعد بدّل حالة الطلب.
- جرّب تسجيل دخول الإدارة وتغيير منتوج، وتأكد من commit ديال ملف JSON فـ repo.

ما تنشرش حتى تدوز هاد الاختبارات بمعلومات اختبار، وتراجع سياسات الخصوصية والبيع الفعلية.
